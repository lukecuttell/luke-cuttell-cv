# Luke Cuttell — Digital Designer & Web Strategist

A two-page, A4, print-ready CV built as semantic HTML/CSS with full responsive web support.

## View

Open `index.html` in a browser.

## Print / Export to PDF

Chrome or Edge → Print → Save as PDF:

- **Paper size:** A4
- **Margins:** None
- **Scale:** 100 %
- **Background graphics:** ON
- **Headers and footers:** OFF

## Features

- Premium editorial design — Cormorant Garamond + Inter typography
- Deep forest green and warm cream palette
- WCAG AA accessible colour contrast
- Semantic HTML for ATS compatibility
- Inline SVG icons (no external dependencies beyond Google Fonts)
- Responsive web layout for mobile and tablet viewing
- Print-optimised with accurate A4 page breaks
- Real, selectable text throughout

## Fonts

[Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) and [Inter](https://fonts.google.com/specimen/Inter) are loaded from Google Fonts.
